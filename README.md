📊 Retail Sales KPI Analysis (SQL Project)

📌 Project Overview

This project is based on a Retail Sales dataset and focuses on deriving business KPIs using SQL.
The analysis helps understand sales performance, profitability, customer behavior, product performance, and regional trends in a retail business environment.

All KPIs are calculated using real-world retail scenarios, making this project suitable for data analyst roles, interviews, and portfolio use.

---

📁 Files Included

1. Retail_Sales.csv

   - Retail transaction data containing:
      - Order details
      - Customer information
      - Product categories
      - Sales, profit, quantity, discount
      - Region and state details

2. STORE.sql

   - SQL file containing KPI queries.
   - Focuses on:
      - Aggregation functions
      - GROUP BY
      - HAVING clause
      - Business-driven KPI logic

---

📊 Retail KPIs Covered

🔹 Sales Performance KPIs

- Total Retail Sales
- Monthly Sales Trend
- Category-wise & Sub-category-wise Sales
- Top & Bottom Selling Products

🔹 Profitability KPIs

- Total Profit
- Profit Margin
- Loss Making Products (identified using HAVING)
- Category-wise Profit Contribution

🔹 Customer KPIs

- Total Unique Customers
- Top Customers by Sales
- Segment-wise Sales Contribution

🔹 Regional KPIs

- Region-wise Retail Sales & Profit
- State-wise Performance
- Loss Making Regions

🔹 Discount & Operational KPIs

- Discount Impact on Profit
- High Discount – Low Profit Products
- Average Order Value (AOV)
- Order Volume Analysis

🚀 How to Run the Project

1. Import "Retail_Sales.csv" into your SQL database.

3. Analyze KPI outputs for retail business insights.
4. (Optional) Build dashboards using Power BI.
